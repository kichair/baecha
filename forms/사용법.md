# 납품서류 만들기

납품계 · 납품확인서 · 사진대지를 한 번에 만드는 프로그램입니다.

## 사용
1. `납품서류_만들기.bat` 더블클릭 (처음 한 번은 필요한 것을 자동 설치합니다. Python 필요)
2. 계약명, 일자, 품목을 입력합니다.
   - 품목은 한 줄에 하나: `품명, 모델명, 수량, 단가`
   - 공급가액·계·계약금액(한글 금액 포함)은 자동 계산됩니다.
3. `사진 추가…`에서 사진을 한꺼번에 선택합니다. 사진 2장마다 사진대지가 1쪽씩 늘어나고, 목록 순서대로 들어갑니다.
   (▲▼로 순서 변경, 파일명순/촬영시간순 선택)
4. `서류 만들기` → 저장 위치 선택 → (PDF 체크 시 같은 이름의 PDF도 같이 저장됩니다. 변환이 안 되면 한글이 자동으로 열리니 `파일 → PDF로 저장하기`)
   → 한글에서 열어 확인 후, 다른 사람에게 줄 때는 `.hwp`로 다시 저장

## 한 번만 설정
- 사업자등록번호: `납품서류_만들기.py` 맨 위 `BIZ_NO = ""` 에 입력
- 도장: 배경이 투명한 `도장.png`를 이 폴더에 넣으면 (인) 위치에 찍힙니다.
- 이전에 입력한 계약명·발주처·품목은 `마지막입력.json`에 저장되어 다음 실행 때 다시 나옵니다.
